# Marco Zero AI - Inteligência Financeira

Sistema revolucionário de diagnóstico financeiro para empresas.

## Getting Started

```bash
npm install
npm run dev
```

## Project Structure

- src/types/ - TypeScript type definitions
- src/agents/ - AI agents for financial analysis
- src/utils/ - Utility functions for calculations
- data/ - Test data

## MVP Plan

Weeks 1-2: Agentes 2, 4, 6
Weeks 3+: Scale to 6 agents
